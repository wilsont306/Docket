# apps/mobile

Expo / React Native iOS client (native camera, share extension, native review UI).

Not yet scaffolded — built at **M4** (iOS to TestFlight) per the build plan in
`docs/PRD.md` §11. Scaffolded with a custom dev client from the start (not Expo Go),
since the M5 share extension requires App Groups + a dev client and cannot be added
to a Expo Go-based project later without redoing the build pipeline (see PRD §12.3).
